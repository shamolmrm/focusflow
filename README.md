# FocusFlow

An AI-powered productivity and habit-tracking app built with Flutter — combining focus sessions, habit tracking, and analytics in one place.

## Features

- Focus session tracking
- Habit building and streaks
- Analytics dashboard for productivity insights
- Onboarding flow
- Profile and app settings
- Premium/upgrade flow

## Tech Stack

- **Flutter / Dart**
- Feature-based architecture

## Project Structure

```
lib/
├── app/            # app entry & routing
├── features/
│   ├── analytics/
│   ├── auth/
│   ├── focus/
│   ├── habits/
│   ├── home/
│   ├── onboarding/
│   ├── profile/
│   ├── settings/
│   └── upgrade/
└── shared/
    ├── models/
    ├── services/
    └── widgets/
```
